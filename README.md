# HGP CareerCheck AI by HRD

A 5-minute AI-powered Hotel Job Interview Simulator built with Express and Google Gemini 2.5 Flash API. Optimized for high speed, direct mobile access via QR Code, and multi-language support (English, Bangla, Banglish).

## Features
- **Instant Access**: No registration, database, or logins.
- **Adaptive AI Interviewer**: Asks role-tailored questions for 13+ hotel departments based on candidate experience and language.
- **5-Minute Countdown Timer**: Auto-completes evaluation when time runs out.
- **Multilingual Support**: Supports English, Bangla, and Banglish input seamlessly.
- **Comprehensive Evaluation**: Generates competency scoring, key strengths, improvement areas, best-fit roles, and AI HR recommendation.
